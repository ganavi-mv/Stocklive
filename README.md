# StockLive – Real-Time Local Inventory Discovery & Navigation Assistant

## Overview
StockLive is a real-time local inventory discovery and navigation platform designed to help consumers locate products in nearby physical retail stores before making a trip.

## Project Structure
- `frontend/` - React + Vite frontend application
- `backend/` - FastAPI Python backend application
- `database/` - PostgreSQL database scripts and migrations
- `docs/` - Project documentation and specifications

## Phase I Scope (10% Prototype)
- Retailer registration & login
- Retailer dashboard
- Store profile creation & editing
- PostgreSQL data persistence
